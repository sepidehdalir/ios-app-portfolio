## Product

- Free complete eight-source-page PDF-to-booklet workflow, saved jobs, reading preview, calibration, export and all print desk tools.
- Saved manual/automatic duplex run,1–100 copy paper estimates, reversible staged user observations and per-job resume.
- Source/blank sheet map and separate portable instruction PDF. Each print export contains ONE booklet; set printer copies separately. Checks are not printer telemetry or proof of physical output.
- Existing non-consumable Lifetime Pro: up to120 source pages, eight reusable printer presets and five independent PDF jobs per batch. Existing identity/data preserved.
