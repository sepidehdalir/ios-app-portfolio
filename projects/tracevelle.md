# Tracevelle: Tracing Lightbox

**Prepare a pattern, then keep it still while tracing.**

Import a reference image, adjust it on screen, calibrate the current setup and lock its position for hand tracing.

[App Store](https://apps.apple.com/us/app/tracevelle-tracing-lightbox/id6816772893) · [Dedicated showcase](https://github.com/sepidehdalir/tracevelle-showcase) · [Product site](https://arvinify.com/apps/tracevelle/)

## Product and engineering

Image transforms; explicit physical calibration; interaction locking during the primary workflow; local image handling.

**Technology:** Swift, SwiftUI, Core Image, PhotosUI, StoreKit 2.
