# Romina Piano — bilingual lesson website

**Live site:** https://romina-piano.arvini.chatgpt.site  
**Source:** [web/romina-piano](../web/romina-piano)

A polished bilingual website for Romina’s piano teaching studio in Tehran, serving online students worldwide and in-person students locally.

## Highlights

- Persian and English language switch with locally written Persian copy.
- Responsive editorial-style layout, lesson details, teaching approach, and FAQ.
- Lesson enquiry form that prepares a message for WhatsApp.
- Direct WhatsApp contact for prospective students.

## Implementation

Static HTML, CSS, and JavaScript. The site is organized as a self-contained Vercel project in `web/romina-piano` with no build step.
